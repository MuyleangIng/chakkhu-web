# Chakkhu ចក្ខុ · Khmer OCR

Website: **https://muyleanging.github.io/chakkhu-web/**

Chakkhu ("eye") is a small Khmer + English OCR model in development by Ing Muyleang: it will read text from
photos, scans, screenshots and chat images. The site shows the planned architecture, the baseline report
(the best free Khmer OCR tools tested on the KHOB benchmark), the training data with licenses, and the roadmap.

From the maker of [Akkhara](https://muyleanging.github.io/akkhara-web/): Akkhara types the letters, Chakkhu reads them.
